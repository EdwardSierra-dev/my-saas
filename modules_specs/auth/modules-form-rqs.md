# Formulario de modulos

### General

- Este menú debe hacerse con las mejores practicas de UI/UX enfocados al tipo de proyecto que se está realizando.

### Seleccion de modulos

- El sistema debe mostrar un modal con 3 mensajes que el usuario podrá ver utilizando un botón de "siguiente"
    - "Selecciona los modulos que más se ajusten a tu necesidad"
    - "Centraliza la operación de tu negocio en un solo lugar"
    - "El control de tu negocio al alcance de tu mano"
- El modal debe tener en la parte de abajo  tres puntos que indican cuantos mensajes son y en cual de los mensajes está parado el cliente.
- Cuando el cliente se encuentre viendo el último mensaje el botón de siguiente debe cambiar el texto a "Empecemos!"
- Una vez hecho el clic en empecemos, debe aparecer un modal con los siguientes checkbox:
    - Chat, al momento de hacer clic o tap sobre la palabra chat debe aparecer un tooltip con el siguiente mensaje:
        - La privacidad y la seguridad de nuestros clientes es lo más importante, chatea con tus clientes sin compartir tus números personales.
    - Domicilios
    - Inventario
    - Notificaciones
    - Promociones
    - Recomendaciones
    - Analitica

- El modulo de Subscription/Billing estará por defecto en las tiendas y no debe aparecer en el modal.

- Estos son los precios que se deben mostrar en cada uno de los modulos:

- Inventory Module > $6 USD/month
- Promotions Module > $4 USD/month
- Scheduling Module > $5 USD/month
- Delivery Module > $6 USD/month
- Reviews & Ratings Module > $3 USD/month
- Recommendation Module > $5 USD/month
- Analytics Module > $7 USD/month
- Chat Module > $5 USD/month

- En el modal debe aparecer un label con el valor final que sería la suma de todos los modulos escogidos.

- Una vez que la tienda escoja y aceptes sus modulos, debe aparecer otro modal donde se le informe que tiene una prueba gratis de 15 días que luego de ese tiempo el soporte se contactará con ellos para validar si se renueva o se elimina la subscripción.
